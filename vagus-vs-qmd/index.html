LOCAL MARKDOWN.

MARKDOWN IN.

Both index files you can read, move, diff, and keep after the search engine is gone.

02

BM25 + VECTORS.

Both combine lexical matching and semantic similarity.

03

RRF IN THE MIDDLE.

Both fuse independent retrieval lists with reciprocal-rank fusion.

Both download model assets once, cache them locally, and infer on your hardware.

05

AGENT OUTPUT.

Both expose structured results for agents.

DERIVED INDEX.

Both keep a local SQLite-backed projection beside durable source files.

INSTALLATION EXAMPLES // PINNED VERSIONS

INSTALL THE TOOL.
ACCOUNT FOR ITS RUNTIME.

Use current project instructions for a new installation.

QMD uses a JavaScript runtime plus native search and inference modules. Vagus ships those dependencies inside a native executable.

BOTH HAVE NATIVE BUILD DEPENDENCIES.
VAGUS // SUPPORTED MAC$ brew tap vasovagal/tap
$ brew trust --tap vasovagal/tap # Homebrew 6+
$ brew install vagus
$ vagus init --icloud
→ five PARA folders + one symlink
QMD // DOCUMENTED NODE PATH$ npm install -g @tobilu/qmd
$ qmd collection add ~/notes --name notes
$ qmd embed
→ collection index + model cache

OPTIONAL SERVER: QMD can run keyword search without models or a daemon. Its HTTP MCP mode keeps models loaded across requests.

QMD CAPABILITIES AT THE PINNED VERSION

COLLECTIONS,
MODELS, AND INTERFACES.

01 // RETRIEVAL

Typed expansion routes lexical queries to BM25 and vector/HyDE queries to semantic search, followed by weighted RRF and local reranking.

02 // REUSE

The SDK, CLI, and MCP server let other applications call retrieval.

03 // CORPUS RANGE

Named collections support project indexes, contexts, code grammars, masks, hooks, and model overrides.

PROJECT-REPORTED MODEL FOOTPRINT~2.04 GB // THREE LOCAL MODELS

QMD documentation reports ~300 MB embedding, ~640 MB reranking, and ~1.1 GB generation assets. URLs and roles were verified in source; files were not downloaded for this audit.
