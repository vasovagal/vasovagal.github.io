## Known-note retrieval probe

Twelve natural-language queries were written against twelve preselected notes across lexical and semantic cohorts. Each query had one grade-3 gold note. The probe asks whether Vagus can find a known memory from a description; it does not estimate open-domain answer correctness.

```sh
vagus index
vagus eval /private/labels.jsonl --mode hybrid --exact --k 10 --json
```

Shipping exact-hybrid RRF result at this corpus size:

| Metric | Result |
|---|---:|
| Gold note found by rank 10 | 12/12 (100%) |
| Gold note at rank 1 | 9/12 (75%) |
| Gold note by rank 3 | 11/12 (91.7%) |
| MRR@10 | 0.8542 |
| mean nDCG@10 | 0.8910 |
| 12-query batch wall time | 15.89 s |
| peak RSS reported by `/usr/bin/time -lp` | 992 MiB |

A second run with the optional context-0 cross-encoder retained 12/12 recall but had MRR@10 0.7875 and nDCG@10 0.8399 on this small sample. That is useful negative evidence: reranking is not a universal quality switch. The bundled agent skill treats it only as a prior and judges every returned full-body candidate before presenting evidence.

## Interpretation and limits

Known-note recall was excellent: every target entered the 10-candidate judgment window. Ordering was strong but not perfect, which supports Vagus's current two-tier design (binary retrieval plus agent body judgment) rather than trusting rank scores as confidence.

This is a small, author-designed, single-corpus probe. Queries were not a frozen external holdout, there were no negative probes, and one gold label per query leaves precision under-judged. Do not generalize the percentages to other vaults or market them as calibrated answer accuracy.
