CHANNEL_A // LEXICALBM25TANTIVY

Tokenize the query, reward rare matching terms, account for repetition and document length, then rank chunks containing the literal vocabulary.

  2. 02weight rare termsIDF(firefox) > IDF(request)

BEST AT filenames, commands, ticket IDs, error strings, product names, and wording you can quote.

CHANNEL_B // SEMANTICVECTOREMBEDDINGGEMMA

Embed the query locally into 768 dimensions, then rank indexed chunks by cosine similarity.

  1. 01prompt as a search querytask: search result | query:
  2. 02embed locallytext → [0.03, −0.11, …] × 768
  3. 03rank by cosinesimilarity can find paraphrases

BEST AT concepts, paraphrases, descriptions, and the memory you can explain but cannot quote.

RECIPROCAL RANK FUSION // k = 60

DON'T MIX SCORES.
MIX RANKS.

Reciprocal rank fusion (RRF) combines positions in the two ranked lists, rather than their differently scaled scores. A chunk receives a contribution from each list in which it appears.

RRF(d) = Σ 1 / (60 + rankchannel(d))

AGENT HANDOFF // READ, JUDGE, CITE

VAGUS RETRIEVES.
YOUR AGENT THINKS.

A shell-capable agent such as pi, Codex CLI, or Claude Code can read full matching chunk bodies and answer from useful evidence. Vagus retrieval runs locally after model downloads; the host agent may send returned text to its model provider.

THE TANDEM

CAPTURE THE RESULT.
APPROVE THE MOVE.

After a capture request, write the outcome to the inbox. Ask Vagus for candidate folders, then review the destination before filing. A retrieval request alone does not authorize creating or moving a note.
