SEPARATE BASE IMAGE
AND APP FINDINGS.

CONTAINER // 80 IDS

Trivy found 80 unique advisory IDs in the measured image: 76 CVEs plus four Debian temporary IDs. Every one was already present in the untouched Bun base image.

GBRAIN APP // 0 IN SNAPSHOT

Trivy's Node-package target reported zero findings, and bun audit returned an empty object. That is a point-in-time result, not a lifetime warranty.

VAGUS LOCK // 2 IN SNAPSHOT

cargo audit found RUSTSEC-2026-0204 and RUSTSEC-2026-0258 in Vagus's 512-package lock plus five informational warnings. This is a dated dependency scan, not a current exploitability assessment.

TRIVY 0.74.0 // 2026-08-21 UTC4 CRITICAL // 12 HIGH // 29 MEDIUM

Also 31 low and four unknown unique IDs. The installed GBrain layer added no OS finding. Trivy did not independently certify the Bun executable, and advisory presence is not proof of reachability or exploitability.

SCAN LIMIT: The report found no advisory in GBrain's scanned Node packages and two in Vagus's Rust lockfile. Base-image findings are separate. Neither result establishes current security or exploitability.

MAINTENANCE AT THE PINNED VERSIONS

MAINTAIN RUNTIMES,
STATE, AND PROVIDERS.

RUNTIME LAYER // VERIFIED

The measured source install used Bun ≥1.3.10 and 188 resolved packages. Binary self-update covers macOS arm64 and Linux x64; source, linked, and compiled installs have different update owners.

STATE LAYER // VERIFIED

127 migrations ran in the empty PGLite brain. Long-term tests must preserve PGLite/Postgres parity, schema packs, pooled database behavior, durable jobs, OAuth, and recovery.

EXTERNAL LAYER // VERIFIED

Twenty-three provider recipes and 69 bundled skills track APIs, models, auth, pricing, deprecations, routing, copied user assets, and provider retirement.

INTERPRETATION // STATE AND INTEGRATIONSSTATE OUTLIVES RUNTIMES

Runtime updates need testing. Database history, provider changes, security fixes, and user-owned skill copies may also need migrations.

VAGUS MAINTENANCE: the pinned version had 512 locked Rust packages, ONNX Runtime, C++ search code, Metal support, model repositories, index formats, and a manually updated Homebrew tap.
