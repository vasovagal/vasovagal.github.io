00 // MANIFESTO

THE FILES ARE THE BRAIN.
EVERYTHING ELSE IS NERVOUS TISSUE.

There is no database holding your thoughts hostage. The source of truth is a folder of Markdown you can open with Vim, Obsidian, Finder, or anything that reads text.

02 // AUDITORY TRANSDUCER

CORTI_

It notices the microphone. It remembers the meeting.

LATEST
0.13.0
2026-08-07

INSTALL IT.
JOIN A CALL.
THAT'S THE SETUP.

Corti watches macOS's microphone-in-use signal. When Zoom, Slack, Google Meet, Discord, or another app grabs the mic, capture begins automatically—and the owning app becomes the source tag.

  • [AUTO] identifies the process using the microphone
  • [DUAL] records your mic and far-end audio separately
  • [LOCAL] Parakeet transcription on CPU or Metal
  • [LIVE] timestamped Me / Them transcript window
  • [DURABLE] streams bounded writes into the vagus inbox

NO CALENDAR HOOK. NO “JOIN MEETING” BOT. NO ACCOUNT.

THE NOTE EXISTS

NOT A TOY VAULT.

This page was checked against one real, iCloud-synced personal corpus on an M1 Pro. Only aggregate measurements are published; note titles, queries, and contents stay private.

Assessment: recall is excellent at this scale; ordering is good, not oracle-perfect. Every gold note entered the 10-item judgment window, while three missed rank one. That is exactly why the skill reads full bodies and makes a final relevance judgment.

Small 12-query, author-designed known-note probe; not a universal benchmark. Exact hybrid RRF, note-level, k=10. The optional reranker also reached 100% recall but lower MRR (0.788), so it remains optional rather than dogma.

04 // AGENT REFLEX ARC

GIVE YOUR AGENT
ACCESS TO MEMORY.

Vagus carries three Agent Skills inside the binary: create a note, search with an explicit quality gate, and propose a PARA destination for the inbox. Install them globally for Claude Code or pi.

  • create-note/SKILL.mdcapture → inbox → index
  • search/SKILL.mdretrieve → rerank → judge → cite
  • process-inbox/SKILL.mdpropose → approve → file
install_reflexes.sh
# Claude Code $ vagus skills install ✓ ~/.claude/skills
# pi coding agent $ vagus skills install --agent pi ✓ ~/.pi/agent/skills
# inspect installation $ vagus skills list --agent pi create-note [installed]
search [installed]
process-inbox [installed]

Idempotent. Re-run after upgrades. In a live pi session: /reload.
