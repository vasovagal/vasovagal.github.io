CREATE A VAULT.

On an Apple Silicon Mac with macOS 15+, Homebrew, and iCloud Drive enabled, run the commands below. The tap uses published release artifacts with pinned checksums. Vagus also ships Linux arm64 and x86_64 builds.

For a local-only vault, use vagus init instead of the final command. If ~/brain already contains notes, iCloud setup stops without moving them; follow the manual migration steps. Run the trust command only on Homebrew 6 or newer.

MODELS, SKILLS,
AND PERMISSIONS.

01

CHECK THE MODELS.

vagus doctor checks vault and index paths, model-file presence, and embedding identity without downloading. To download and validate the embedder and reranker explicitly, run vagus doctor --fetch-models. First indexing or search can also download needed models.

02

INSTALL AGENT SKILLS.

Run vagus skills install for Claude Code or vagus skills install --agent pi for pi. Reinstall after Vagus upgrades; use /reload in an existing pi session. Codex CLI can call Vagus through the shell. The host agent may send retrieved note text to its model provider.

03

SET UP CORTI.

Launch Corti and grant Microphone and System Audio Recording permissions. In Settings, select and download local models, then use the idle microphone test before joining a call. AWS transcription and hosted text features require separate configuration; see processing choices.
